# Jarri Workspace Core 0.4.0 — A more flexible workspace

Version 0.4.0 makes Jarri Workspace Core easier to navigate,
customize, and extend.

Discover tools through a searchable panel catalogue, manage crowded
tab bars with scrolling, wrapping, and compression, and personalize
your workspace with expanded appearance controls.

The release also introduces the first-party Workspace Diagnostics
module and strengthens the runtime infrastructure behind panels.

Existing capabilities include the File Browser, Calendar, text and
image viewers, and workspace screenshot tools.

**Release status:** Unpublished release candidate. Final native
verification and distribution integration remain outstanding.

## What's new

- Scroll or wrap the tab strip, optionally compress tab buttons, and drag tabs
  to reorder them. Existing tab identities and the selected tab are preserved.
- Find registered panels through searchable Add Panel and workspace-wide Open
  Panel search. Arrange the spatial catalogue and resize or reposition it.
- Adjust panel corner radius, use configurable glass effects, and set an
  optional gradient canvas wallpaper independently of theme selection.
- Choose the Dashboard Night community theme, contributed by Sh0ken (Kenny).
- Use the Core Calendar panel, including ISO week labels and calendar copy
  workflows, and open it from the Workspace clock.
- Capture the full logical workspace or an individual frame as an image through
  Workspace-owned screenshot controls.
- Open Runtime Diagnostics, Runtime Events, and Runtime Inspector from the
  first-party Workspace Diagnostics module. Core records runtime timing and
  provides registries for observation leases and explicit resource-byte claims.
- Use the reusable, opt-in virtual-list presentation utility where a panel
  chooses to adopt it. Runtime Events also offers an opt-in virtualized history
  view.

## Compatibility and limitations

Saved layouts and tab templates migrate the exact legacy panel identities
`core/runtime-diagnostics`, `core/runtime-events`, and
`core/runtime-inspector` to the `workspace-diagnostics` module identity when
that module is available. Layout migration retains panel IDs, panel state,
geometry, tab placement, selection-channel preferences, Runtime Events'
virtualization and scroll preferences, and surface presentation memory. If the
module is unavailable, the legacy panel remains recoverable through Missing
Panel behavior. Templates migrate the identities and geometry; their existing
format does not persist per-panel state. No workspace schema-version bump is
required for these identity migrations.

Virtualization is opt-in and does not set producer retention limits. Diagnostics
does not report total process RAM or GPU memory. Resource-byte rows represent
only explicit `exact-known` claims; empty registries mean evidence is not
provided. Core currently has no backend observation producer. The adopted
native-surface host remains a Linux-specific experimental integration.

The canvas grid remains visible with gradient wallpapers and uses the
selected theme's border colour. ChronoGit's logo retains its transparent
background, and Settings numeric values no longer shift adjacent controls
as their character lengths change.

Core is distributed as source. There is no automatic binary download,
installation, or restart path. This release candidate has not been published;
update awareness only reports an update if an application is configured with a
valid HTTPS source-release metadata endpoint.

## Source update guidance

When a 0.4.0 source publication is made, use its published repository revision
or source archive. For a clean checkout tracking `master`, first preserve or
commit local work, then run:

```sh
git status --short
git fetch origin
git pull --ff-only origin master
npm install
npm run tauri -- dev
```

Review the fetched revision before switching branches or updating a customized
checkout. The metadata URL may link to these published release notes; it does
not update the checkout itself. Do not treat an arbitrary local branch or
uncommitted tree as an official release.

## Planned work (not included in this candidate)

- Backend, execution, and projection observation producers and richer
  application-specific diagnostics.
- Cross-platform adopted native-window hosting and broader native integration
  validation.
- Persistent integrated terminals with independently owned PTY sessions
  and recovery across Workspace restarts (targeted for 0.5.0).
- Broader per-panel adoption of virtual lists where appropriate.

Clean-machine native verification and Jarri-Distribution alignment are
outstanding **0.4.0 publication gates**, not deferred features.
